Strava 接入向导(2 分钟搞定)

需要先在 Strava 注册一个 API App,拿到 Client ID + Client Secret。每个用户都用自己的,不会暴露给别人。

1
注册 App
点下面按钮打开 Strava 设置页,点 Create App。
App Name: 随便填(如 cycling-dashboard)
Website: 随便填
Authorization Callback Domain: 必须填 localhost
2
复制凭据
注册成功后页面上会显示 Client ID 和 Client Secret(点 Show 露出 secret)。复制后粘到左边设置面板的输入框,点 保存。
3
授权连接
回到本面板点 连接 Strava,浏览器会跳到 Strava 让你点 Authorize。完成后自动跳回看板,以后上传 .fit 就能同步了。
